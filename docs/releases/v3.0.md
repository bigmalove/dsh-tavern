# DSH Tavern v3.0 变更记录

从 **v2.7 到 v3.0 共 474 个提交**，其中 81 个是自动生成的运行时清单提交，13 个是合并提交。统计范围为 `v2.7..2e1ae548`，详见[完整提交清单](v3.0-commits.md)。

**这一版重点：换到 DSH 0.2.1，带来 DSH 人物卡、Galgame 式演出和第 3 版插件接口。**

v3.0 适配 **DSH 0.2.1**：官方 DeepSeek Harness 0.2.1-rc.2、社区版 DSH NEXT、手机 DSHA v0.2.0-rc2，或自带 DSH 的命令行版。人物卡可以带素材包和插件，一张卡就能演成视觉小说；正文旁有说话人头像，右侧有舞台，台词可以按人物声音朗读。

还在用 DSH 0.1.5（DSH Desktop 2.0.13、旧一键安装包）的，请继续用**稳定版**：它移到了 [`stable` 分支](https://github.com/flizzywine/dsh-tavern/tree/stable)，只修严重问题，安装和更新都跟随 `stable`。

## 换到 DSH 0.2.1

- 支持的宿主：官方 DeepSeek Harness 0.2.1-rc.2、DSH NEXT（与官方版共用 `.dsh` 数据目录）、DSHA v0.2.0-rc2（内置 DSH 0.2.0-rc.2）。命令行版自带锁定的 DSH 0.2.1-rc.2，不修改全局 DSH。
- 宿主版本改为允许清单：清单外的版本，安装器在改动任何文件前停止；还在用 DSH 0.1.x 的，提示改装稳定版。
- 旧存档：打开后在「酒馆状态」点「迁移存档」。正文、变量、分支和历史版本都保留，完成后入口自动隐藏。迁移后的存档不要再交给旧宿主读取。
- 旧酒馆在自定义目录时，安装可以把数据一并继承过来，迁移前会备份双方数据，遇到冲突就停止。
- 桌面版装好后直接进入酒馆，不需要切换 Profile；要回到原版 DSH，在「设置 → Profile 切换」里选「原版 DSH」并立即重启。
- 不再提供一键安装包：Windows 改为下载一个安装文件双击运行，或者粘贴一行 PowerShell 命令；Android 在 DSHA 的终端里粘贴一行命令。

## DSH 人物卡（.dshcard）

- 新的卡格式：一张普通的 Character Card V3，再加素材包和卡内插件。它是 CHARX 的超集，去掉专有部分仍是合法的 CCv3 卡。
- 素材包：立绘、背景、音乐、Live2D 等成套素材按内容存储，同样的文件只存一份。
- 卡内插件随卡启用，只在这张卡的局里生效；内容相同的插件多张卡共用一份。
- 卡可以带推荐预设和开局设置，导入即可玩。
- CCv3 / CHARX 卡带的立绘和背景照常导入，也能导出成 CHARX。
- 同一个卡文件再导入，直接打开卡库里原来那张，不再多出「(1)」。
- 样板卡「大肥鱼」：4 个素材包、导演插件、全身立绘舞台、背景音乐和本局配置项。制作方法见[DSH 人物卡制作](../dshcard-guide.md)和[开发实例：大肥鱼](../dshcard-tutorial.md)。

## 演出：对话头像、舞台与配音

- 对话头像：后台结算时顺带标注每句台词的说话人和情绪，正文里台词显示成带头像的一行，头像随情绪换图；点头像可以放大查看。
- 舞台：「酒馆状态」顶部的小舞台可以展开全屏，逐句翻页、自动播放，读到最后一句直接输入。舞台按人物卡开关；带自己舞台的卡，进入游戏时直接显示。
- 角色素材：在舞台页上传头像和各情绪立绘，也能导入 SillyTavern 立绘包。
- 背景音乐由 Tavern 播放，舞台上方有音乐开关，离开这一局就停。
- 配音：台词按人物各自的声音朗读，新增独立的配音设置页；新增火山引擎（豆包 V3）渠道，插件也能添加渠道。开了配音，舞台默认朗读。

## 插件接口第 3 版

- 舞台与轮次：`settlementTask` 新增 `phase: 'parallel'`，与 Tavern 自己的结算同时运行；`versionSignal` 在正文版本被回退、重新生成或编辑时中止插件的任务；`publishState` / `watchState` 把插件的最新状态推给它自己的页面。
- 上下文：`getRequestContext` 按段给出这一轮正文请求实际用到的上下文，标明来自 Tavern、预设还是哪个插件。
- 人物卡：改卡可以带 `expectedRevision`，不会覆盖期间别人的修改；`onCardChanged` 通知卡的改动；插件可以写角色素材、建素材包，用 `cardImporter` 导入 Tavern 不认识的卡格式。
- 界面：`registerStatusSection` 往「酒馆状态」加一节，`registerTurnView` 换整轮正文的显示方式（拿到 Tavern 渲染好的正文作 `children`）。
- 配音与 Skill：配音渠道收到局、说话人和是否旁白，`version` 计入缓存；`skillSource` 让插件自带只读 Skill。
- 第 2 版里新增的部分：人物卡库读写、插件工具可见范围、Skill 读写、人物设计档案读写、演出数据（台词标注、角色素材、舞台画面、朗读）、本局配置项、`registerCardListView`、`castAssetSource`。
- 外部插件提议的「快照 token + 两阶段提交」没有采用，理由见[插件开放层设计](../plugin-design.md)。详见[插件接口文档](../plugin-api.md)。

## 游玩

- 正文可以改走工具调用（`submit_story`），全局设置里打开。另有「历史正文也走工具调用」开关，默认关闭：历史正文以工具参数的形式发给模型，降低一些模型续写时的拒答。
- 失败或中止的最新一轮可以「撤回这条输入」，恢复到这一轮开始前。
- SillyTavern 聊天记录支持批量导入，每份记录各自处理「仅导入正文」和玩家称呼。
- 人物卡库和开始游玩窗口可以切到封面宫格视图（吸收自 swp-z 的插件）。
- 「完整上下文」里每一节显示大约多少 token。
- 本局设置精简成游玩、模型、功能、高级 4 个分区；编辑正文时整轮在一个编辑框里改。
- 新游戏先以卡名命名，不再显示成「resources」。

## 存档

- 回退、重新生成、编辑正文、撤销回退改为以存档为准：模型上下文与存档对不上时自动修复，不再拒绝操作。
- 修复多处并发写入覆盖：共享会话索引、同一张卡、同一份预设、同一来源的世界书条目、剧本绑定。
- 导出、导入存档时，生图快照、插图和人物卡资源都能完整往返。

## 修复

- 上下文压缩：模板同步不再把压缩检查点改写回玩家原文（#202）；压缩提示及时更新、可以手动关闭（#205）；智谱的超长报错也会触发压缩后重试（#206）。
- 分叉出的游玩会话后续每轮保存失败（#204）；一轮有多条模型消息时，分叉与生图按钮消失（#234）。
- 带工具调用的一轮，正文不再按步骤重复显示（#222、#223）。
- 含模板世界书的聊天记录导入失败（#237）；只有行首的 `@@` 才算模板装饰器。
- 手机：进入游戏不再自动弹出右侧栏（#213）；输入框按钮的外观与命中区（#215）；卡片锁住触控时页面无法滚动（#239）。
- 桌面：Windows 标题栏的拖拽区挡住弹层（#231）；底部面板入口压住侧栏开关、删完最后一局后入口消失（#244）。
- 更新：Windows 桌面版环境校验必定失败、重装时报 EPERM，以及更新按钮被锁一小时（#232）；从 Git 仓库运行时不再启动应用内更新。
- DSH 0.2 改了工具结果的结构，三处跟上：「正文走工具调用」认不出提交、正文取成空；前台读到的世界书资料交接不到后台；「历史正文也走工具调用」的回执结构不对。
- DSH NEXT：没有在运行 Agent 的会话里，Skill 菜单出错。
- 侧聊：子会话恢复之后，侧聊面板丢掉恢复前的历史（Better Sidebar 补丁）。
- 长存档批量恢复变慢：每恢复一条消息都要复制整份事件日志。
- 卡死或失败后被替换的后台 Agent，子智能体列表接口不再列出。
- 插件接口：`backgroundModel` 返回本局的后台推理强度（#203）。
- 卡片工作台：`tavern_validate_card` 可以校验预设和世界书（#210）。
